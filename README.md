# STN-7 Problem Solving Assessment

## Overview

This repository contains my solutions to the STN-7 Problem Solving Assessment using JavaScript. The solutions are organized in a single JavaScript file.

## Technologies Used

- JavaScript (ES6+)
- Node.js
- Node.js built-in `assert` module for testing

## How to Run

### Prerequisites

Install [Node.js](https://nodejs.org/) on your computer.

### Run the Solutions and Tests

Open a terminal in the project directory and run:

```bash
node solution.js
```

The script executes the solutions and their associated tests. Successful tests display a `PASSED` message.

## Testing

The project uses Node.js's built-in `assert` module to verify expected outputs. The test cases cover sample inputs for the implemented problems.
